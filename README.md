# Weather-Forecast-App ☀️🌧️🌡️

A dynamic web-based Weather Forecast Application that provides real-time weather updates for any location. Built using HTML, CSS, and JavaScript, and powered by the OpenWeatherMap API for accurate weather data.

## 🌐 Features

- 🌤️ Real-time weather updates for any city
- 📱 Responsive user interface for mobile and desktop
- 🛰️ Integration with OpenWeatherMap API
- 💡 Displays temperature, weather conditions, humidity, and wind speed
- 🚫 Error handling for invalid city names

## 🛠️ Technologies Used

- **HTML** – Structure and layout
- **CSS** – Styling and responsive design (with gradient background)
- **JavaScript** – API integration and dynamic content rendering
- **OpenWeatherMap API** – Real-time weather data source
